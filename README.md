## 主要功能

- 自动种植、收获、铲除、补种和仓库读取。
- 好友农场巡查、偷菜、帮助和特殊作物兜底。
- QQ/Lite 与微信/CDP 双链路支持。
- 桌面壳、Web 控制台和本地运行日志。
- 受保护发布包完整性校验、公益声明和公开验证文件。

## 使用说明

1. 解压发布包到英文或短路径目录。
2. 运行 `Windows_start.bat`。
3. 根据实际环境选择 QQ 或微信模式。
4. 打开对应农场页面，等待控制台显示上下文就绪。
5. 按需开启自动农场或单项任务。

微信模式目前要求用户手动打开微信农场页面；自动检索和自动打开微信宿主属于后续功能。
